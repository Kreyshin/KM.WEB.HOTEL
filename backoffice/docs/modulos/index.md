# Los módulos

La barra izquierda agrupa el sistema en siete módulos. Al pulsar uno se abre un segundo panel con sus secciones; al elegir, el panel se retira y deja todo el ancho al trabajo.

| Módulo                                  | Para qué                                     | Quién lo usa               |
| --------------------------------------- | -------------------------------------------- | -------------------------- |
| [Inicio](/modulos/inicio)               | El parte del día y el tablero en vivo        | Todos                      |
| [Alojamiento](/modulos/alojamiento)     | Habitaciones, plano, tipos y pisos           | Recepción y administración |
| [Reservas](/modulos/reservas)           | Agenda, mostrador y huéspedes                | Recepción                  |
| [Pisos](/modulos/housekeeping)          | Limpieza, mantenimiento y consumible         | Gobernanta y mantenimiento |
| [Tarifas](/modulos/tarifas)             | Precio por tipo, día y canal                 | Administración             |
| Admin                                   | Producción, facturación, usuarios y bitácora | Administración             |
| [Configuración](/modulos/configuracion) | Sedes, políticas y motivos                   | Administración             |

## Lo que se repite en todas las pantallas

Vale la pena conocerlo una vez:

- **La sede activa**, arriba a la derecha, manda sobre todo lo que se ve. Cambiarla recarga la pantalla con los datos de ese establecimiento.
- **La búsqueda global** (`Ctrl` + `K`) encuentra secciones, habitaciones y huéspedes desde cualquier punto.
- **Los listados** comparten buscador, filtros, orden por columna, paginación y exportación a CSV o Excel.
- **El tema** claro u oscuro se cambia desde tu perfil, abajo a la izquierda, y se recuerda entre sesiones.
- **Los avisos** aparecen arriba a la derecha y se van solos. Los de error duran más, porque suelen pedir una decisión.
