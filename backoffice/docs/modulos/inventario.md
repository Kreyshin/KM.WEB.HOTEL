# Amenities y lencería

El consumible que el carro repone en cada habitación.

## Las categorías

| Categoría     | Ejemplos                        |
| ------------- | ------------------------------- |
| Amenities     | Kit de shampoo, jabón, gel      |
| Lencería      | Sábanas, toallas                |
| Limpieza      | Desinfectante, producto de baño |
| Minibar       | Agua, snacks                    |
| Mantenimiento | Focos, pilas, repuestos menores |

## Stock y mínimo

Cada insumo lleva su **stock mínimo**. Por debajo, la fila se marca en coral con el aviso «bajo mínimo».

No es una alarma decorativa: quedarse sin juegos de sábanas a media mañana paraliza la planta entera.

## Movimientos

El kardex del piso. Qué entró, qué salió y —cuando aplica— **a qué habitación se imputó**.

| Tipo    | Qué significa                                 |
| ------- | --------------------------------------------- |
| Ingreso | Llega material: compra o vuelta de lavandería |
| Salida  | Se consume: reposición o consumo de minibar   |
| Ajuste  | Corrección tras un inventario físico          |
| Merma   | Se pierde: manchas irreversibles, rotura      |

El stock se cuadra en la misma operación: no hay un paso aparte que alguien pueda olvidar. Y no deja sacar más de lo que hay — el aviso dice cuánto queda.
